# Echosystem agent bootstrap

This file is a non-authoritative discovery map. It owns no product,
architecture, security, or development policy.

Before writing:

1. Read the current task and inspect the current repository, branch, and
   worktree state.
2. Read only the canonical owners relevant to the change:
   - `PRODUCT.md` — product purpose and product invariants;
   - `ARCHITECTURE.md` — stable boundaries and concern ownership;
   - `SECURITY.md` — security, privacy, trust, and authority obligations;
   - `DEVELOPMENT.md` — development, evidence, review, and merge obligations.
3. Use current code, configuration, migrations, tests, Git, GitHub, CI, and
   runtime state for the current facts they own.

`README.md` is navigation, not a competing semantic owner. Historical plans,
research reports, Jarvis artifacts, issue comments, sessions, and agent memory
are evidence rather than current repository authority.

Do not infer undecided implementation choices. Where a load-bearing obligation
has an executable mechanism, follow that mechanism from its current machine
owner rather than restating it here.
