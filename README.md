# Axey

Axey is a learning personal operating partner.

It works alongside one person over time: it takes in what is going on in their
life and work, keeps track of what matters, and helps them decide and act. It
is meant to get better at this the longer it is used, by learning that person's
context, priorities and preferences rather than being configured up front.

Axey is not a coding assistant and not a development framework. Software
development is only how Axey itself gets built.

## Status

Early. This repository currently holds the founding documents and nothing else.
No application code, no stack decision, no CI.
